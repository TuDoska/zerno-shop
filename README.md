# ☕ Зерно — інтернет-магазин кави

Повноцінний інтернет-магазин свіжообсмаженої кави, чаю й аксесуарів. У ньому є каталог із фільтрами, кошик, оформлення замовлення, особистий кабінет і адмін-панель.

> Демонстраційний проєкт для портфоліо. Бренд вигаданий, ілюстрації товарів намальовані кодом (SVG), реальні оплати не проводяться.

## Можливості

**Для покупця**
- Каталог: категорії, тип обсмаження, діапазон цін, сортування, пошук за назвою, країною та смаковими нотами.
- Сторінка товару: варіанти ваги, помел, кількість, характеристики, відгуки з позначкою «покупка підтверджена», схожі товари.
- Кошик у `localStorage`. Ціни щоразу перераховує сервер, тому підмінити їх у браузері неможливо.
- Промокоди (відсоток або фіксована сума, мінімальна сума замовлення) і шкала «до безкоштовної доставки».
- Оформлення: валідація полів, Нова Пошта (відділення або курʼєр) чи самовивіз, спосіб оплати.
- Сторінка замовлення зі статусом. Гість відкриває її за секретним посиланням, користувач бачить її в кабінеті.
- Обране й історія замовлень в особистому кабінеті.

**Для власника (адмінка)**
- Огляд: виручка, середній чек, графік виручки за 14 днів (SVG), топ товарів, товари, що закінчуються.
- Замовлення: фільтр за статусом, зміна статусу. Скасування замовлення повертає товар на склад.
- Товари: створення, редагування, приховування, залишки на складі.
- Промокоди: створення, увімкнення й вимкнення, лічильник використань.
- Ролі: адміністратор і менеджер.

## Технології

Node.js, Express, MongoDB (Atlas) / NeDB, JWT у httpOnly cookie, bcrypt, Helmet (CSP), rate limiting, Vanilla JS, CSS Grid і Flexbox, адаптивна верстка.

## Запуск

```bash
npm install
npm start        # http://localhost:3000
npm test         # інтеграційні тести
```

Без `MONGODB_URI` дані зберігаються у файлах у папці `data/`. Перший зареєстрований користувач стає адміністратором. Тестові промокоди: `ZERNO10` (−10%) і `WELCOME` (−100 ₴ від 800 ₴).

## Структура

```
server/
  index.js      — Express, безпека, маршрути
  db.js         — MongoDB або NeDB з однаковим API
  auth.js       — JWT, ролі
  pricing.js    — розрахунок кошика, доставки, промокодів
  seed.js       — стартові товари
  routes/       — auth, shop (каталог, кошик, замовлення, відгуки, обране), admin
public/         — сторінки, стилі, JS, SVG-ілюстрації
test/           — тести API
```
